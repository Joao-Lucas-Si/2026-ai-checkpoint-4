# Regras
- Identificar informações principais no input do usuario e dos chatbots
- Manter palavras-chave importantes para manter o contexto e facilitar o processamento
- Preservar dados importantes como nomes, numeros, datas, condições ou requisitos
- Não alterar o significado original
- Organizar as informações de forma claras e objetivas
- Reduzir o conteudo sem eliminar informações necessarias
